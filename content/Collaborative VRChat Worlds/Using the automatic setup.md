## Prerequisites
- A Unity Project folder
- Nothing else, the installer will guide you through it and install everything you need

## Steps to use
- Download the .bat file from [here](https://github.com/LemonadeSpice/Automatic-Collaborative-Worlds-Setup/releases/tag/LTS)
- Place it right outside your Unity Project folder
- Run it
- Follow the setup

## What it does
- Installs git and git cli latest versions
- Prompts you to log in (or sign up) to GitHub by opening a link in browser
- Asks you for permission to run git cli on your account (needed to create and upload a repository on github)
- Lets you select a folder to set up as a git repository (this is where you'll pick your Unity Project folder)
- Sets up the repository, adds .gitignore and initializes git lfs for it
- Creates a local initial commit
- Creates a remote repository in GitHub
- Links it and uploads the initial commit
